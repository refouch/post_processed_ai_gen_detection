### Data collection and processing

The dataset must be downloaded manually from this website: https://zenodo.org/records/14963880

ONLY download the 20GB ```RRDataset_test.tar.gz``` acrhive, the other one is irrelevant to us, and unpack it as is in this folder

The provided csv linking each image to its test split should work correctly provided you unpack the archive as is. If for any reason an error occurs, run the ```data_processing.py``` script which should generate a fresh csv with the correct file paths.
